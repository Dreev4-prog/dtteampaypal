# DT Team PayPal Bot v1.3.1

## Что нового

- Кнопочный раздел **«👥 Участники»** в `/admin`.
- Списки: все, активные, ожидающие, отклонённые и заблокированные.
- Постраничный вывод по 10 пользователей.
- Поиск по Telegram ID, `@username` и имени.
- Карточка участника: имя, username, ID, статус, даты, администратор и число выданных PayPal.
- Управление доступом из карточки: одобрить, отклонить, заблокировать, разблокировать и отозвать доступ.
- Кнопка для открытия личного диалога с участником.
- В базе автоматически добавляется поле `full_name`; ручная миграция не нужна.

## Обновление Railway

1. Загрузите все файлы архива в корень GitHub-репозитория с заменой.
2. Дождитесь успешного автоматического деплоя Railway.
3. Переменные `BOT_TOKEN`, `ADMIN_IDS` и `DATABASE_URL` менять не нужно.
4. В Telegram отправьте `/admin` и откройте **«👥 Участники»**.

## Проверка

- Откройте списки по каждому статусу.
- Найдите пользователя по ID или username.
- Откройте карточку и измените статус.
- Проверьте, что пользователь получил уведомление и его доступ изменился.

Добавление PayPal по-прежнему доступно командой:

```text
/addtags @tag1 @tag2 @tag3
```
