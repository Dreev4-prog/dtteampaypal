# DT Team PayPal Bot v2.2.6

## Изменения интерфейса администратора

- Очередь PayPal оставлена первой кнопкой на главной админ-панели.
- «PayPal и платежи» переименован в «Работа с PayPal».
- Выплаты вынесены отдельной кнопкой на главную админ-панель.
- В «Работе с PayPal» собраны проверка оплат, PayPal в работе, свободные, возвраты, GS, Gestop и добавление PayPal.
- Внутренний дублирующий поиск удалён; остался один общий поиск на главной админ-панели.

- Платежи и база PayPal объединены в раздел «💳 PayPal и платежи».
- Внутри: платежи, база, возвраты, выплаты и поиск.
- Переходы назад ведут в единый центр.

# DT Team PayPal Bot v2.2.1 — Wallet Update

## Главное меню пользователя

- 💳 Получить PayPal
- 📂 Мои PayPal
- 💰 Кошелёк
- 👤 Личный кабинет
- 🛟 Поддержка

Раздел «Мои PayPal» и его существующая логика не изменялись.

## Кошелёк

В одном разделе объединены:

- доступный накопительный баланс;
- текущий способ выплаты CryptoBot / xRocket;
- общая выплаченная сумма;
- количество выплат;
- последняя выплата;
- изменение способа выплаты;
- история отправленных выплат и чеков.

Пользователь может открыть любую выплату из истории и запросить отправку сохранённого чека повторно.

## Совместимость

- Использует существующую PostgreSQL базу версии 2.2.
- Новые переменные Railway не требуются.
- Вся логика накопления общего баланса и ручной выплаты одним чеком сохранена.
