# DT Team PayPal Bot v1.1

Версия с фирменными баннерами на экранах пользователя.

## Что добавлено

- баннер главного меню;
- баннер выбора суммы PayPal;
- баннер профиля;
- баннер истории заявок;
- баннер ссылок и поддержки;
- баннер выдачи PayPal;
- при нажатии кнопок текущее сообщение заменяется новым экраном;
- чат не засоряется отдельными сообщениями при обычной навигации.

## Обновление через GitHub

1. Распакуйте архив.
2. Загрузите **содержимое** папки в корень репозитория с заменой файлов.
3. Нажмите `Commit changes`.
4. Railway автоматически создаст новый deployment.

Переменные Railway менять не нужно:

- `BOT_TOKEN`
- `ADMIN_IDS`
- `DATABASE_URL`

## Команды администратора

- `/admin`
- `/addtags @tag1 @tag2 @tag3`

Перед публичным запуском замените в `app/handlers.py`:

- `@your_channel`
- `your-site.com`
- `@your_support`
