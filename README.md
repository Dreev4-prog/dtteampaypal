# DT Team PayPal Bot v2.1 — Content + GS Fix

В сборке сохранены все предыдущие исправления и добавлен редактор контента в админ-панели.

## Раздел «📝 КОНТЕНТ»

Через админ-панель теперь можно без изменения кода:

- менять текст главного приветствия;
- загружать и удалять картинку главного экрана;
- менять текст экрана «Получить PayPal»;
- менять текст поддержки;
- сбрасывать каждый текст к стандартному варианту.

Данные сохраняются в PostgreSQL (`app_settings`) и применяются сразу. В приветствии можно использовать `{status}` — бот автоматически подставит текущий режим сервиса.

## Также сохранено

- GS-скриншот отправляется владельцу выданного PayPal;
- «Оплата не найдена» возвращает пользователю возможность повторной проверки;
- исправлены кнопки админ-панели;
- фирменные изображения v2.1.
