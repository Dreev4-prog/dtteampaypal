# DT Team PayPal Bot — этап 1

Рабочая базовая версия Telegram-бота для Railway.

## Уже работает

- главное меню;
- создание заявки по сумме;
- уведомление администраторов;
- добавление PayPal-тегов командой `/addtags`;
- одноразовая выдача тега из PostgreSQL;
- кнопка «Я оплатил»;
- ручное подтверждение или отметка «Оплата не найдена»;
- профиль и история заявок.

## Переменные Railway

- `BOT_TOKEN`
- `ADMIN_IDS`
- `DATABASE_URL`

В Railway при добавлении PostgreSQL переменная часто называется `DATABASE_URL`.
Для SQLAlchemy URL должен начинаться с:

`postgresql+asyncpg://`

Если Railway выдаёт `postgresql://`, замените начало строки вручную.

## Команды администратора

- `/admin`
- `/addtags @tag1 @tag2 @tag3`
