# DT Team PayPal Bot v1.6.3

## Новое

- Личный раздел пользователя **«Мои PayPal»** с группировкой заявок по этапам.
- Раздел **«Мои профиты»**: выплачено всего, количество и средняя выплата, ожидающая сумма, последние выплаты.
- Лимит в две активные заявки теперь учитывает только заявки со статусом `waiting_issue`, то есть запросы, по которым PayPal ещё не выдан.
- Выданные PayPal, проверка оплаты, ожидание выплаты и завершённые заявки больше не занимают лимит новых запросов.
- В карточках отображаются актуальная сумма, PayPal-тег, сумма к выплате и статус.

## Обновление

Замените файлы проекта содержимым архива. Переменные Railway и база данных не требуют изменений.

# DT Team PayPal Bot v1.6

## Новое в v1.6

- Настраиваемые проценты выплат прямо из админ-панели.
- Стартовые правила: от 50 € — 60%, от 100 € — 70%.
- Можно добавлять, менять и удалять пороги без обновления кода.
- После подтверждения оплаты процент и сумма к выплате рассчитываются автоматически.
- Пользователь получает уведомление с суммой, процентом и итоговой выплатой.
- В карточке платежа отображаются процент и сумма к выплате.
- Изменение суммы в очереди выплат автоматически пересчитывает выплату.
- Новый раздел «Финансы» и показатели на главном экране администратора.
- Старые заявки в статусе «Нужно выплатить» пересчитываются при запуске.

## Обновление

Замените файлы проекта содержимым архива и отправьте изменения в GitHub. Railway выполнит деплой автоматически. Переменные `BOT_TOKEN`, `ADMIN_IDS` и `DATABASE_URL` менять не нужно.

## Команды

- `/start` — открыть бот.
- `/admin` — админ-панель.
- `/addtags @tag1 @tag2` — добавить PayPal-теги.

- После проверки возврата: вернуть в базу, Gestop или удалить.

## v1.6.5 — Start Work / Stop Work

- Управление режимом работы из админ-панели.
- START WORK открывает создание новых заявок и рассылает редактируемое уведомление всем одобренным участникам.
- STOP WORK блокирует только создание новых заявок; уже выданные PayPal, подтверждение оплаты, возвраты и выплаты продолжают работать.
- Тексты Start Work и Stop Work редактируются непосредственно в админ-панели и хранятся в PostgreSQL.
