# DT Team PayPal Bot v1.2

## Новое в версии 1.2

- полноценная кнопочная админ-панель по команде `/admin`;
- добавление PayPal через кнопку, без обязательного использования команд;
- списки свободных и выданных PayPal;
- поиск PayPal по тегу;
- безопасное удаление только свободных PayPal;
- экран остатка PayPal;
- список заявок с фильтрами по статусу;
- карточка заявки и обработка через кнопки;
- список последних пользователей;
- общая статистика и статистика за последние 24 часа;
- старые команды `/admin` и `/addtags` сохранены для совместимости.

## Обновление через GitHub

1. Распакуйте архив.
2. Загрузите содержимое архива в корень текущего репозитория с заменой файлов.
3. Сделайте Commit changes.
4. Railway автоматически начнёт новый deployment.

Переменные Railway менять не нужно:

- `BOT_TOKEN`
- `ADMIN_IDS`
- `DATABASE_URL`

После запуска отправьте боту `/admin`.

Перед публичным запуском замените в `app/handlers.py` значения:

- `@your_channel`
- `your-site.com`
- `@your_support`
