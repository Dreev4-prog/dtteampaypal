# DT Team PayPal Bot v2.2.1 — Wallet Update

## Главное меню пользователя

- 💳 Получить PayPal
- 📂 Мои PayPal
- 💰 Кошелёк
- 👤 Личный кабинет
- 🛟 Поддержка

Раздел «Мои PayPal» и его существующая логика не изменялись.

## Кошелёк

В одном разделе объединены:

- доступный накопительный баланс;
- текущий способ выплаты CryptoBot / xRocket;
- общая выплаченная сумма;
- количество выплат;
- последняя выплата;
- изменение способа выплаты;
- история отправленных выплат и чеков.

Пользователь может открыть любую выплату из истории и запросить отправку сохранённого чека повторно.

## Совместимость

- Использует существующую PostgreSQL базу версии 2.2.
- Новые переменные Railway не требуются.
- Вся логика накопления общего баланса и ручной выплаты одним чеком сохранена.
