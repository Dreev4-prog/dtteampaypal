# DT Team PayPal Bot v2.2.2

## Изменения

- В списке «PayPal в работе» вместо ID показываются пользователь, PayPal-тег и сумма.
- В карточке выданного PayPal появилась кнопка «Деньги поступили».
- Процент определяется автоматически по правилам из раздела «Проценты».
- Рассчитанная сумма автоматически добавляется в накопительный кошелёк пользователя.
- Повторное нажатие не создаёт повторное начисление.
- При административном изъятии PayPal сначала попадает в существующий раздел «Возвраты».
- В «Возвратах» администратор после проверки выбирает: вернуть PayPal в работу, пометить Gestop или удалить.
- Массовое изъятие PayPal за день также направляет их в «Возвраты», а не сразу в свободную базу.
- Разделы «Участники» и «Статистика» объединены в «Пользователи и статистика».
- «Мои PayPal», кошелёк и ручные выплаты сохранены без изменения основной логики.

## Деплой

Замените файлы проекта в GitHub. Переменные Railway и PostgreSQL вручную менять не требуется.
